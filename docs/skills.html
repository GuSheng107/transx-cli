MODES

三种调用方式

首次使用时选择一种模式。

PY推荐

Python 脚本

通过 Python 调用 DLX。

  • 需要 Python 3
  • PDF 使用 pdfplumber
  • JSON 输出
JS脚本

Node.js 脚本

使用 Skill 内的 Node.js 脚本。

  • 需要 Node.js 18+
  • 固定依赖版本
  • JSON 输出
TXCLI

TransX CLI

安装并使用 transx 命令。

  • 需要 Node.js > 22
  • 文本与文件翻译
  • 交互界面

INSTALL

安装 Skill

使用 npx 或下载 ZIP。

  1. 01
    npx 安装

    npx skills add GuSheng107/transx-cli --skill transx-translate -g

  2. 02
    ZIP 安装

    解压后复制整个 transx-translate 文件夹。

  3. 03
    首次配置

    选择模式并输入 DLX API Key。
