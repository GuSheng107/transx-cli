ONE CHOICE, THREE WORKFLOWS

三种调用方式

Agent 先报告检测结果，再由用户选定一种方式。选定后，其余方式不会继续出现在 Skill 提示词中。

PY推荐

Python 脚本

仅使用 Python 标准库，直接请求 api.deeplx.org，无需安装 TransX CLI。

  • 需要 Python 3
  • 仅支持纯文本翻译
  • 输出稳定 JSON
JS脚本

Node.js 脚本

使用随 Skill 附带的单文件请求脚本，适合已有 Node.js 环境的用户。

  • 需要 Node.js 18+
  • 无需安装 CLI
  • 输出稳定 JSON
TXCLI

TransX CLI

通过安装命令部署完整 CLI，Skill 随后专门指导 Agent 使用 transx。

  • 仅支持 Node.js > 22
  • 自动安装或复用 CLI
  • 完整命令行能力

一套历史记录

Python 脚本、Node.js 脚本与 TransX CLI 均写入 ~/.transx/history/，切换调用方式也不会割裂记录。

切换模式只更新本地 Skill 文档与偏好；附带脚本和已安装的 CLI 都会原样保留。

INSTALL

安装 Skill

推荐使用官方 Skills CLI 从 GitHub 仓库安装；也可以下载 ZIP，手动放入 AI 工具能够发现 Skill 的目录。

  1. 01
    推荐：使用 npx 安装

    运行 npx skills add GuSheng107/transx-cli --skill transx-translate -g，由 Skills CLI 自动安装到选定 Agent。

  2. 02
    备选：下载 ZIP

    解压 transx-skills.zip，将整个 transx-translate 文件夹复制到 Skills 根目录。

  3. 03
    向 Agent 发起翻译

    首次调用会检测环境、确认三种现有模式之一并安全配置 DeepLX API Key。
