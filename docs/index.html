TransX CLI 服务

在终端调用 DeepLX 翻译服务，让多语言处理更直接。

TransX CLI v0.1.0

欢迎来到 TransX CLI！

  1. 查看帮助：运行 transx help 获取完整指令。
  2. 初始化配置：运行 transx init，输入 DeepLX URL 模板与 API Key。
  3. 翻译文本：transx translate "Hello" --to ZH --json
  4. 查看配置：transx config
  5. 检查更新：transx version --check，升级：transx update

_

npx transx-cli install

要求 Node.js > 22。安装后重新打开终端即可使用。
