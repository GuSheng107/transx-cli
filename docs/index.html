01
INSTALL / ONE COMMAND

三端，同一条安装命令。

需要已安装 Node.js > 22。npm 包发布后，命令会安装到当前用户目录并自动配置 PATH。

› npx transx-cli install

安装入口：%LOCALAPPDATA%\.transx\bin\transx.cmd

03
COMMAND INDEX

指令保持少而明确。

无兼容别名、无隐式服务。运行 transx help 查看同一份帮助。

指令用途适用对象
transx init初始化 URL 模板和 API Key用户
transx translate翻译参数文本或 stdin用户 / AI
transx config查看脱敏配置与路径用户
transx version --check检查 npm 最新版本用户
transx update更新用户目录中的版本用户
--to <lang>目标语言，必填 --source <lang>源语言，默认 auto --format <type>plain / html / xml --json稳定 JSON 输出 --timeout <sec>单次请求超时
04
AI CONTRACT / STDOUT + STDERR

给 AI 的不是界面，是稳定契约。

固定使用 --json。成功内容写入 stdout；失败内容写入 stderr，并返回非零退出码。

05
CONFIGURATION

URL 和 Key 始终分开。

程序只在发起请求时将 {key} 替换为本地 Key，不展示拼接后的完整 URL。

transx config set-url重设 URL 模板
transx config set-key隐藏输入新 Key
transx config reset url仅清除 URL
transx config reset key仅清除 Key
transx config reset all清除全部配置
URL TEMPLATE https://your-deeplx.example/{key}/translate

示例域名仅作格式说明，不是可用翻译服务。

07
BOUNDARY / READ BEFORE USE

你的接口，也意味着你的判断。

01 URL 与 Key 不编译进源码、npm 包或文档。

02 待翻译内容会发送到你配置的第三方服务。

03 不收集遥测，不提供公共 DeepLX 节点。

04 TransX 与 DeepL SE、DeepLX 服务方无隶属或背书关系。
