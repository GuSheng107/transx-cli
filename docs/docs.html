INTERACTIVE

不带子命令时打开交互界面，适合用户直接操作；非交互环境会输出帮助，不会阻塞 AI 或脚本。

transx
02
COMMAND

transx help

在终端输出完整指令列表、翻译参数与常用示例。

transx help
参数无。也可以使用 transx --help 或 transx -h。
03
COMMAND

transx init

首次初始化或同时替换 DeepLX URL 模板与 API Key。URL 必须包含 {key} 占位符。

transx init [--url <url>] [--key-stdin]

专属参数

参数作用
--url <url>直接传入包含 {key} 的 URL 模板；省略时交互输入
--key-stdin从 stdin 读取 API Key；省略时隐藏输入

示例

transx init

自动化示例：printf '%s' "$DEEPLX_API_KEY" | transx init --url 'https://your-deeplx.example/{key}/translate' --key-stdin

04
AI CORE COMMAND

transx translate

翻译命令行文本或 stdin。AI 调用建议固定加 --json，便于稳定解析成功和失败结果。

transx translate [text] --to <lang> [options]

专属参数

参数作用默认值
[text]待翻译文本；省略时从 stdin 读取stdin
-t, --to <lang>目标语言，必填，例如 ZH、EN—
-s, --source <lang>源语言auto
--format <plain|html|xml>输入内容格式plain
--json输出适合 AI 读取的单行 JSON关闭
--timeout <seconds>仅设置本次请求的超时时间，必须为正数20
-h, --help显示 CLI 帮助—

示例

transx translate "Hello world" --to ZH --json

stdin：echo "Hello world" | transx translate --to ZH --json

兼容别名EN → EN-US，PT → PT-BR

此列表与 DeepLX v1.2.2 源码同步。不同版本或兼容服务的实际范围可能不同。

COMMAND GROUP

transx history

查看、搜索或清理本地翻译历史。成功翻译自动记录原文和译文，不记录 URL 或 API Key。

transx history [list|search|status|clear|help]

transx history [list]

按时间倒序查看记录。省略 list 时行为相同，默认显示 20 条。

参数作用
--limit <n>本次返回条数，默认 20
--offset <n>跳过前 n 条，默认 0
--from <time>仅返回此时间及之后的记录
--to <time>仅返回此时间及之前的记录
--since <Nd>查看最近 N 天，例如 7d；不能与 --from 同用
--json输出适合程序读取的单行 JSON
transx history --limit 50 --offset 100 --json

transx history search <keyword>

不区分英文大小写，同时搜索原文和译文；任一包含关键词就返回，可匹配多条。支持与查看命令相同的 --limit、--offset、时间范围和 --json 参数。

transx history search "环境审查" --limit 50 --json

transx history status [--json]

显示历史目录、记录数量、文件总量、最早和最新记录，以及是否需要清理。

transx history clear <mode>

参数作用
--oldest <n>删除最旧的 n 条
--keep <n>只保留最新的 n 条
--before <time>删除指定时间之前的记录
--older-than <Nd>删除早于最近 N 天的记录，例如 30d
--from <time> --to <time>删除指定时间范围内的记录，两项必须同时提供
--all删除全部记录
--yes跳过确认；非交互环境必须提供
--json以 JSON 返回删除条数
transx history clear --older-than 30d --yes

存储与时间

目录~/.transx/history/
文件index.json 与 YYYY-MM-DD.json
提醒超过 30 天或 100 MB，每天最多一次

记录不限制条数，也不会自动删除。时间统一按中国时间处理，格式为 YYYY-MM-DD HH:mm:ss.SSS，不附带时区标记。运行 transx history help 可在终端查看此命令组帮助。

07
COMMAND GROUP

transx config

查看完整 URL 模板和原 API Key，或分别维护本地配置。

transx config [set-url|set-key|reset]

transx config

参数无。输出 URL 模板、完整 API Key、初始化状态和配置文件路径。

transx config set-url [url]

参数作用
[url]新的 URL 模板，必须包含 {key}；省略时交互输入

transx config set-key [--stdin]

参数作用
--stdin从 stdin 读取新的 API Key；省略时隐藏输入

transx config reset <target>

参数作用
url仅删除本地 URL 模板
key仅删除本地 API Key
all同时删除本地 URL 与 API Key

示例

transx config set-url "https://your-deeplx.example/{key}/translate"

环境变量 DEEPLX_URL_TEMPLATE 与 DEEPLX_API_KEY 会覆盖本地配置，但不会写入配置文件。

08
COMMAND

transx install

把当前包安装到用户目录并配置 PATH，支持 Windows、macOS 与 Linux。

transx install [--force]

专属参数

参数作用
--force覆盖用户目录中已存在的同版本安装

首次安装

npx transx-cli@latest install

要求 Node.js > 22。安装完成后重新打开终端。

AI CONTRACT

JSON 与错误码

仅 translate --json 使用以下稳定契约：成功写入 stdout，失败写入 stderr，并返回非零退出码。

SUCCESSEXIT 0
{
  "ok": true,
  "data": "你好，世界",
  "source_lang": "auto",
  "target_lang": "ZH",
  "provider": "deeplx-compatible"
}
ERROREXIT ≠ 0
{
  "ok": false,
  "error": {
    "code": "CONFIG_NOT_INITIALIZED",
    "message": "缺少 DeepLX URL 或 API Key，请先运行 transx init"
  }
}

错误码

code含义exit
INVALID_ARGUMENT参数错误2
CONFIG_NOT_INITIALIZED未初始化配置3
CONFIG_INVALID配置无效3
NETWORK_ERROR网络或超时4
API_HTTP_ERRORDeepLX 返回错误5
API_RESPONSE_INVALID响应格式无效6
HISTORY_ERROR历史文件读取、写入或锁定失败7
INSTALL_ERROR安装失败5
UPDATE_ERROR更新失败5
CANCELLED用户取消130
