01
COMMANDS

指令列表

运行 transx help 可随时查看完整帮助。

指令用途说明
transx help显示完整指令与示例入口
transx init初始化 URL 模板和 API Key用户
transx translate <text>翻译参数文本或 stdin用户 / AI
transx config查看脱敏配置与路径用户
transx config set-url设置 URL 模板用户
transx config set-key隐藏输入新 API Key用户
transx config reset <url|key|all>重置指定配置用户
transx install [--force]安装到用户目录并加入 PATH用户
transx version [--check]显示版本，可检查 npm 最新版用户
transx update从 npm Registry 更新到最新版用户
02
OPTIONS

参数说明

translate 子命令支持以下参数。

参数说明默认
-t, --to <lang>目标语言（必填）—
-s, --source <lang>源语言auto
--format <plain|html|xml>内容格式plain
--json输出适合 AI 读取的 JSON关闭
--timeout <seconds>本次请求超时20
-h, --help显示帮助—

init 参数

参数说明
--url <url>非交互式传入 URL 模板
--key-stdin从 stdin 读取 API Key

环境变量

变量说明
DEEPLX_URL_TEMPLATE覆盖本地 URL 模板
DEEPLX_API_KEY覆盖本地 API Key
03
OUTPUT

返回格式

使用 --json 时，成功写入 stdout；失败写入 stderr，并返回非零退出码。

SUCCESSEXIT 0
{
  "ok": true,
  "data": "你好，世界",
  "source_lang": "auto",
  "target_lang": "ZH",
  "provider": "deeplx-compatible"
}
ERROREXIT ≠ 0
{
  "ok": false,
  "error": {
    "code": "CONFIG_NOT_INITIALIZED",
    "message": "缺少 DeepLX URL 或 API Key"
  }
}

错误码

code含义exit
INVALID_ARGUMENT参数错误2
CONFIG_NOT_INITIALIZED未初始化配置3
CONFIG_INVALID配置无效3
NETWORK_ERROR网络或超时4
API_HTTP_ERRORDeepLX 返回错误5
API_RESPONSE_INVALID响应格式无效6
INSTALL_ERROR安装失败5
UPDATE_ERROR更新失败5
CANCELLED用户取消130
04
TUTORIAL

简要教程

01

查看帮助

先确认当前版本支持的全部指令。

transx help
02

安装

安装到用户目录并自动配置 PATH，随后重新打开终端。

npx transx-cli install
03

初始化配置

URL 必须包含 {key} 占位符，API Key 采用隐藏输入。

transx init

非交互环境：printf '%s' "$DEEPLX_API_KEY" | transx init --url 'https://your-deeplx.example/{key}/translate' --key-stdin

04

翻译文本

AI 调用推荐始终使用 --json。

transx translate "Hello world" --to ZH --json

stdin：echo "Hello" | transx translate --to ZH --json

05

配置管理

查看脱敏配置，或修改 URL / Key。

transx config
06

版本与更新

检查并更新到 npm 最新版。

transx version --check && transx update
